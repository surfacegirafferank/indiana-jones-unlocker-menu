## 🧩 About

**Indiana Jones catalog Menu** is a curated list of Indiana Jones open-source tools:

- **Overlays** — on-screen helpers, layout notes, objective viewer, checkpoint switcher
- **Quality-of-Life Helpers** — inventory catalog, relic manager, overlay notes
- **Research Notes** — puzzle layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Adventure Helpers
- Checkpoint Switcher — practice from any checkpoint
- Show Collectibles — visualize relic and artifact locations
- Replay Notes — record and review level runs
- Playback Speed — adjust puzzle timing for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Artifact Catalog — browse relics, journal entries, outfits
- Custom Outfit Notes — organize player cosmetics
- Journal Highlight — improved journal visibility

### 🏋️ Practice Layout
- Puzzle Mode Notes — segment study on any layout
- Hidden Passage Control — manually reveal secret paths mid-level
- Jump Buffer Notes — chain complex maneuvers in the editor
